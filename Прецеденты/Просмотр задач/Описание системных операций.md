# Описание Системных Операций

## 1. Операция: `viewTaskList()`

**Ссылки:**  
Прецеденты: Просмотр списка задач.

### **Предусловия**
- Пользователь аутентифицирован в системе.
- Исполнитель имеет доступ к системе задач.

### **Постусловия**
- Система получает и отображает список доступных задач.
- Если список пуст, выводится уведомление о недоступности задач.

### **Действия**
1. Исполнитель вызывает метод `TaskSystem::viewTaskList()`.
2. Система инициирует запрос к объекту `TaskList` для получения списка задач.
3. `TaskList` обращается к объекту `Task` для получения подробностей о задачах.
4. Задачи возвращаются обратно в `TaskList`.
5. Если задачи отсутствуют, система уведомляет исполнителя о недоступности задач.
6. Если задачи имеются, список задач отображается исполнителю.

--- 

## 2. Операция: `getTasks()`

**Ссылки:**  
Прецеденты: Получение списка задач.

### **Предусловия**
- Система получает запрос на получение списка задач.

### **Постусловия**
- Задачи получены из системы и переданы на дальнейшую обработку.

### **Действия**
1. Система вызывает метод `TaskList::getTasks()`.
2. Метод извлекает все доступные задачи из базы данных или другого хранилища.
3. Задачи передаются в объект `TaskList` для дальнейшей обработки.

---

## 3. Операция: `fetchTaskDetails()`

**Ссылки:**  
Прецеденты: Получение подробностей о задачах.

### **Предусловия**
- В системе есть доступные задачи.
- Система должна получить подробности каждой задачи.

### **Постусловия**
- Детали каждой задачи получены и готовы к отображению.

### **Действия**
1. Система вызывает метод `TaskList::fetchTaskDetails()`.
2. Запрашиваются подробности для каждой задачи, связанные с описанием, сроками и другими данными.
3. Детали задач передаются обратно в объект `TaskList`.

---

## 4. Операция: `displayTaskList()`

**Ссылки:**  
Прецеденты: Отображение списка задач.

### **Предусловия**
- Задачи были получены и подготовлены для отображения.

### **Постусловия**
- Список задач отображен исполнителю для выбора.

### **Действия**
1. Система вызывает метод `TaskSystem::displayTaskList()`.
2. Система отображает список задач на интерфейсе исполнителя.
3. Исполнитель видит все доступные задачи для дальнейшего выбора.

---

## 5. Операция: `notify(message: String)`

**Ссылки:**  
Прецеденты: Уведомление исполнителя.

### **Предусловия**
- Система должна уведомить исполнителя о событиях (например, отсутствии доступных задач).

### **Постусловия**
- Исполнитель получает уведомление.

### **Действия**
1. Система вызывает метод `TaskSystem::notify()`.
2. Уведомление отправляется исполнителю (например, через интерфейс или сообщения).
3. Исполнитель получает информацию о текущем состоянии (например, "Нет доступных заданий").
