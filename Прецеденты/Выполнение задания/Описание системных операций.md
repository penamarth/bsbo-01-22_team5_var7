# Описание Системных Операций

## 1. Операция: `selectTask(taskID: TaskID)`

**Ссылки:**  
Прецеденты: Выбор задачи.

### **Предусловия**
- Пользователь аутентифицирован в системе.
- Задача с идентификатором `taskID` существует в системе.

### **Постусловия**
- Задача с идентификатором `taskID` выбрана для дальнейшей работы.
- Детали задачи загружены в систему для отображения.

### **Действия**
1. Система вызывает метод `TaskSystem::selectTask(taskID)`.
2. Информация о задаче извлекается из базы данных.
3. Пользователь видит подробности задачи в интерфейсе.

---

## 2. Операция: `startTask(taskID: TaskID)`

**Ссылки:**  
Прецеденты: Запуск задачи.

### **Предусловия**
- Задача выбрана и готова к запуску.
- Система готова начать обработку задачи.

### **Постусловия**
- Задача стартует, создается экземпляр задачи в системе.
- Исполнитель уведомлен о начале выполнения задачи.

### **Действия**
1. Система вызывает метод `TaskSystem::startTask(taskID)`.
2. Создается экземпляр задачи в системе.
3. Исполнитель получает уведомление о начале работы.

---

## 3. Операция: `updateProgress(taskID: TaskID, progress: integer)`

**Ссылки:**  
Прецеденты: Обновление прогресса задачи.

### **Предусловия**
- Задача находится в процессе выполнения.
- Исполнитель обновляет прогресс выполнения задачи.

### **Постусловия**
- Прогресс задачи обновлен в системе.
- Исполнитель уведомлен о текущем прогрессе.

### **Действия**
1. Система вызывает метод `TaskSystem::updateProgress(taskID, progress)`.
2. Прогресс задачи фиксируется в базе данных.
3. Исполнитель уведомляется о текущем прогрессе.

---

## 4. Операция: `pauseTask(taskID: TaskID)`

- Исполнитель инициирует приостановку задачи.

### **Постусловия**

- Исполнитель уведомлен о приостановке задачи.

### **Действия**
1. Система вызывает метод `TaskSystem::pauseTask(taskID)`.
2. Задача приостанавливается в базе данных.
3. Исполнитель уведомляется о приостановке задачи.

---

## 5. Операция: `resumeTask(taskID: TaskID)`

### **Предусловия**

### **Постусловия**
- Задача возобновляется в системе.
- Исполнитель уведомлен о возобновлении работы.

### **Действия**
1. Система вызывает метод `TaskSystem::resumeTask(taskID)`.
2. Задача возобновляется в базе данных.
3. Исполнитель уведомляется о возобновлении задачи.

---

## 6. Операция: `completeTask(taskID: TaskID)`

**Ссылки:**  
Прецеденты: Завершение задачи.

### **Предусловия**
- Задача завершена и готова к обработке.
- Исполнитель подтвердил завершение работы.

### **Постусловия**
- Задача завершена в системе.
- Данные о выполнении отправлены в бухгалтерскую систему.

### **Действия**
1. Система вызывает метод `TaskSystem::completeTask(taskID)`.
2. Задача помечается как завершенная в системе.
3. Данные передаются в бухгалтерскую систему для учета.

---

## 7. Операция: `sendWorkData(taskID: TaskID, duration: integer)`

**Ссылки:**  
Прецеденты: Отправка данных о времени работы задачи.

### **Предусловия**
- Задача завершена.
- Время выполнения задачи зафиксировано.

### **Постусловия**
- Данные о времени работы задачи отправлены в бухгалтерскую систему.
- Бухгалтерская система получила необходимые данные для расчета.

### **Действия**
1. Система вызывает метод `Task::sendWorkData(taskID, duration)`.
2. Данные о времени работы передаются в бухгалтерскую систему.
3. Информация о передаче сохраняется в логе.

---

## 8. Операция: `notifyCompletion(taskID: TaskID)`

**Ссылки:**  
Прецеденты: Уведомление о завершении задачи.

### **Предусловия**
- Задача завершена и подтверждена.
- Необходимо уведомить исполнителя о завершении задачи.

### **Постусловия**
- Исполнитель уведомлен о завершении задачи.

### **Действия**
1. Система вызывает метод `TaskSystem::notifyCompletion(taskID)`.
2. Исполнитель получает уведомление о завершении работы.
3. Лог уведомлений сохраняется в системе.

---
