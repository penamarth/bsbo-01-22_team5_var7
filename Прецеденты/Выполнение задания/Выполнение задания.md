## Прецедент: Выполнение задания в системе учета рабочего времени

### 1. Рамки

Приложение - Система учета рабочего времени.

### 2. Уровень

Задача, определенная пользователем.

### 3. Основной исполнитель

Исполнитель задачи.

### 4. Заинтересованные лица и их требования

- Исполнитель задачи. Хочет точно и быстро выполнить задачу, не допуская ошибок в процессе работы над ней.
- Бухгалтерская система. Хочет получить корректные данные о работе исполнителя для своевременного обновления учета.

### 5. Предусловия

- Исполнитель задачи идентифицирован и аутентифицирован.
- Задача выбрана из списка задач.

### 6. Результаты (Постусловия)

- Задача завершена.
- Данные о выполнении задачи сохранены в системе.
- Бухгалтерская система обновлена.

### 7. Основной успешный сценарий

1. Исполнитель выбирает задачу из списка.
2. Система предоставляет детали выбранной задачи.
3. Исполнитель начинает работу над задачей.
4. В течение работы исполнитель регулярно обновляет прогресс.
5. При достижении 100% прогресса система уведомляет исполнителя о готовности к завершению.
6. Исполнитель завершает работу над задачей.
7. Система финализирует выполненную задачу и отправляет данные в бухгалтерскую систему.
8. Исполнитель получает подтверждение о завершении работы.

### 8. Расширения

#### 8.1. Пауза задачи

1. Исполнитель запрашивает паузу для выбранной задачи.
2. Система сохраняет текущий прогресс и состояние задачи.
3. Исполнитель может продолжить работу позже, возобновив задачу.

#### 8.2. Возобновление работы над задачей

1. Исполнитель запрашивает возобновление работы над задачей.
2. Система восстанавливает состояние задачи и прогресс.
3. Исполнитель продолжает работу над задачей с сохраненного состояния.

### 9. Специальные требования

- Интерфейс системы должен быть удобным для использования исполняемым пользователем.
- Система должна обеспечивать надежное хранение и восстановление данных о задачах.
- Возможность локализации отображаемого текста для разных языков.
- Возможность добавления новых бизнес-правил в процессе работы над системой.

### 10. Список технологий и типов данных

- Использование базы данных для хранения информации о задачах и прогрессе.
- Возможность интеграции с бухгалтерской системой для обновления данных.
- Использование алгоритмов для расчета прогресса и времени выполнения задачи.

- Какие типы пользователей могут потребовать специфичных функций в системе?
