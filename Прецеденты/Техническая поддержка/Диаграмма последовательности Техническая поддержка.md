```plantuml
@startuml
left to right direction
actor SystemsAdministrator as SA
participant "MonitoringTool" as MT
participant "SupportService" as SS
participant "SystemLogs" as Logs
participant "Database" as DB
participant "NotificationService" as NS

== System Check Initiation ==
SA -> MT : startMonitoring()
MT -> SS : checkSubsystems()
SS -> DB : checkDatabaseStatus()
DB --> SS : returnStatus()
SS -> Logs : analyzeLogs()
Logs --> SS : returnLogData()
SS --> MT : generateReport()

== Problem Detection ==
MT --> SA : notifyIssue()
SA -> Logs : getDetailedLogs()
SA -> SS : runDiagnostics()

== Problem Resolution ==
SA -> SS : resolveIssue()
SS -> DB : applyFix()
DB --> SS : confirmFix()
SS -> NS : sendNotification("Issue resolved")

== Completion ==
NS --> SA : confirmCompletion()
@enduml
```
