
**Прецедент:** Сбор статистики по рабочему времени в системе учета рабочего времени

**Рамки**

*   **Приложение:** Система учета рабочего времени

**Уровень**

*   Задача, определенная пользователем (руководителем)

**Основной исполнитель**

*   Руководитель

**Заинтересованные лица и их требования**

*   **Руководитель:** Хочет получить статистический отчет по рабочему времени сотрудников, затраченному на выполнение задач и проектов, для анализа и принятия управленческих решений.
*   **Система бухгалтерии:** Должна корректно собирать и обрабатывать данные из различных систем для формирования отчета.
*   **Система управления проектами:** Должна предоставлять актуальные данные о проектах и задачах.
*   **HR-система:** Должна предоставлять актуальные данные о сотрудниках и их заработной плате.

**Предусловия**

*   Руководитель аутентифицирован в системе учета рабочего времени.
*   Система учета рабочего времени, система управления проектами и HR-система доступны и работают корректно.
*   В системах имеются данные о проектах, задачах, сотрудниках и их рабочем времени.

**Результаты (Постусловия)**

*   Руководитель получает статистический отчет по рабочему времени в соответствии с заданными параметрами.
*   Система бухгалтерии обновляет логи запросов и формирует запись о выполненном отчете.

**Основной успешный сценарий (Основной процесс)**

| Шаг | Действие пользователя (Руководитель) | Действие системы                                                                       | Ожидаемый результат                                                                                                                                |
|-----|---------------------------------------|---------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| 1   | Запрос на формирование отчета, указав период и фильтры (RequestForStat(period, filters)) | Система учета рабочего времени принимает запрос и передает его в систему бухгалтерии.   | Запрос принят, начинается процесс формирования отчета.                                                                                             |
| 2   |                                       | Система бухгалтерии запрашивает данные о проектах у системы управления проектами (getProjectData(filters)). | Запрос данных о проектах отправлен.                                                                                                                |
| 3   |                                       | Система управления проектами обрабатывает запрос и возвращает данные о проектах (projectData). | Данные о проектах, соответствующих фильтрам, получены системой бухгалтерии.                                                                      |
| 4   |                                       | Система бухгалтерии запрашивает данные о сотрудниках у HR-системы (getEmployeeData(filters)).    | Запрос данных о сотрудниках отправлен.                                                                                                             |
| 5   |                                       | HR-система обрабатывает запрос и возвращает данные о сотрудниках (employeeData).      | Данные о сотрудниках, соответствующих фильтрам, получены системой бухгалтерии.                                                                   |
| 6   |                                       | Система бухгалтерии компилирует статистический отчет на основе полученных данных (compilingStatistics(projectData, payrollData, employeeData)). | Отчет сформирован.                                                                                                                               |
| 7   |                                       | Система бухгалтерии передает отчет руководителю (DataOfStat(report)).                 | Руководитель получает отчет по рабочему времени.                                                                                                |

**Специальные требования**

*   Интерфейс системы учета рабочего времени должен быть интуитивно понятным для руководителей, предоставляя удобные средства для задания параметров отчета.
*   Система должна обеспечивать быстрый доступ к данным и формирование отчета в разумное время, даже при больших объемах данных.
*   Система должна вести лог запросов на формирование отчетов и результатов их выполнения.
*   Формат отчета должен быть удобным для чтения и анализа (например, таблицы, графики, word файлы).
