# Описание системных операций для формирования статистики

## Участники

*   **Руководитель** (Manager): Инициатор запроса на формирование статистики.
*   **Система бухгалтерии** (Money Management): Основная система, ответственная за сбор и обработку данных, а также формирование отчета.
*   **Система управления проектами** (Project Management System): Предоставляет данные о проектах.
*   **HR-система** (HR System): Предоставляет данные о сотрудниках и заработной плате.

## Системные операции

### 1. Запрос статистики (RequestForStat)

*   **Инициатор:** Руководитель
*   **Участник:** Система бухгалтерии
*   **Описание:** Руководитель отправляет запрос на формирование статистики в систему бухгалтерии. Запрос включает в себя:
    *   `period`: Период, за который необходимо сформировать статистику.
    *   `filters`:  Фильтры для отбора данных (например, по проектам, сотрудникам, отделам).
*   **Входные данные:**
    *   `period` (дата, период)
    *   `filters` (список условий фильтрации)

### 2. Получение данных о проектах (getProjectData)

*   **Инициатор:** Система бухгалтерии
*   **Участник:** Система управления проектами
*   **Описание:** Система бухгалтерии запрашивает у системы управления проектами данные о проектах, соответствующие заданным фильтрам.
*   **Входные данные:**
    *   `filters` (список условий фильтрации)
*   **Выходные данные:**
    *   `projectData` (структура данных, содержащая информацию о проектах, такую как:
        *   Идентификатор проекта
        *   Название проекта
        *   Бюджет проекта
        *   Затраты по проекту
        *   Сроки проекта
        *   Другие релевантные данные)

### 3. Получение данных о сотрудниках (getEmployeeData)

*   **Инициатор:** Система бухгалтерии
*   **Участник:** HR-система
*   **Описание:** Система бухгалтерии запрашивает у HR-системы данные о сотрудниках, соответствующие заданным фильтрам.
*   **Входные данные:**
    *   `filters` (список условий фильтрации)
*   **Выходные данные:**
    *   `employeeData` (структура данных, содержащая информацию о сотрудниках, такую как:
        *   Идентификатор сотрудника
        *   ФИО сотрудника
        *   Должность
        *   Отдел
        *   Заработная плата
        *   Ставка
        *   Другие релевантные данные)

### 4. Компиляция статистики (compilingStatistics)

*   **Инициатор:** Система бухгалтерии
*   **Участник:** Система бухгалтерии
*   **Описание:** Система бухгалтерии обрабатывает полученные данные (`projectData`, `employeeData`) и формирует статистический отчет. Это может включать в себя расчеты различных показателей, агрегацию данных, группировку и т.д.
*   **Входные данные:**
    *   `projectData` (данные о проектах)
    *   `employeeData` (данные о сотрудниках)
*   **Выходные данные:**
    *   `report` (структура данных, содержащая статистический отчет, готовый для представления руководителю. Может включать в себя:
        *   Таблицы
        *   Графики
        *   Диаграммы
        *   Ключевые показатели эффективности (KPI)
        *   И другую аналитическую информацию)

### 5. Предоставление данных статистики (DataOfStat)

*   **Инициатор:** Система бухгалтерии
*   **Участник:** Руководитель
*   **Описание:** Система бухгалтерии предоставляет руководителю сформированный статистический отчет.
*   **Входные данные:**
    *   `report` (сформированный отчет)
