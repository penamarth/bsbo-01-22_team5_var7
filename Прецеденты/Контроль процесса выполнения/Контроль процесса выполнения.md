## Прецедент: Управление обновлением и завершением задачи


### 1. Основной исполнитель
Менеджер.

### 2. Заинтересованные лица и их требования
- **Менеджер**: Хочет своевременно обновлять задачи и контролировать их завершение.
- **Исполнитель задачи**: Хочет получать уведомления о статусе задач.
- **Система управления задачами**: Должна обеспечивать корректное управление статусами задач.
- **Система уведомлений**: Должна точно уведомлять пользователей об изменениях статуса задачи.

### 3. Предусловия
- Менеджер идентифицирован и аутентифицирован.
- Задача выбрана для обновления или проверки.

### 4. Результаты (Постусловия)
- Задача обновлена с новой информацией.
- Менеджер уведомлен о завершении задачи.
- Исполнитель уведомлен о принятии или отклонении задачи.

### 5. Основной успешный сценарий

#### Обновление задачи
1. Менеджер выбирает задачу для обновления.
2. Система сохраняет обновленные данные задачи в базе данных.
3. Менеджер получает подтверждение об успешном обновлении.
4. Система уведомляет исполнителя об обновлении задачи.

#### Проверка завершенной задачи
1. Менеджер запрашивает детали завершенной задачи.
2. Система извлекает данные из базы.
3. Менеджер проверяет данные задачи.
4. Система уведомляет исполнителя о результате проверки:
   - **Если задача принята**:
     1. Система обновляет статус задачи на «принята».
     2. Исполнитель получает уведомление о принятии.
   - **Если задача отклонена**:
     1. Менеджер указывает причину отклонения.
     2. Система обновляет статус задачи на «отклонена».
     3. Исполнитель получает уведомление об отклонении.

#### 6. Уведомления
- Уведомления отправляются через систему уведомлений при любом изменении статуса задачи.

### 7. Специальные требования
- Надежное и безопасное хранение данных задач в базе данных.
- Поддержка отправки уведомлений в реальном времени.
- Удобный интерфейс для проверки и обновления статуса задач.


---

Диаграмма описывает процессы управления задачами в системе, выполняемые менеджером и исполнителем. Основные этапы:

### Уведомление работника об обновлении задачи
- Менеджер обновляет задачу, отправляя данные через систему управления задачами (TaskManagementSystem).
- Система сохраняет изменения в базе данных.
- Менеджер получает подтверждение о сохранении изменений.
- Система уведомлений отправляет уведомление исполнителю о том, что задача обновлена.

### Участвующие компоненты:
- **Manager** — инициирует обновление задачи.
- **TaskManagementSystem (TMS)** — сохраняет изменения.
- **Database (DB)** — обновляет данные задачи.
- **NotificationService (NS)** — уведомляет исполнителя.
- **Worker** — получает уведомление об обновлении задачи.
