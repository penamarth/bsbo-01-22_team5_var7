## Описание операций в системе управления задачами

### 1. Операция: Обновление задачи
**Описание**: Процесс, в котором менеджер вносит изменения в данные задачи и уведомляет исполнителя об обновлении.  
**Участники**:  
- **Manager**: Инициирует обновление задачи.  
- **TaskManagementSystem (TMS)**: Обрабатывает изменения и сохраняет их в базе данных.  
- **Database (DB)**: Сохраняет обновленные данные задачи.  
- **NotificationService (NS)**: Уведомляет исполнителя о произошедших изменениях.  
- **Worker**: Получает уведомление об обновлении задачи.  

**Поток выполнения**:  
1. Менеджер выбирает задачу и вносит изменения.  
2. Система управления задачами сохраняет изменения в базе данных.  
3. Менеджер получает подтверждение об успешном обновлении.  
4. Система уведомлений отправляет уведомление исполнителю о том, что задача обновлена.  

---

### 2. Операция: Проверка завершенной задачи
**Описание**: Менеджер проверяет завершенную задачу, принимает или отклоняет ее, уведомляя исполнителя о результате.  
**Участники**:  
- **Manager**: Проверяет завершенную задачу и принимает решение о принятии или отклонении.  
- **TaskManagementSystem (TMS)**: Извлекает данные о задаче из базы, обновляет статус задачи, уведомляет исполнителя.  
- **Database (DB)**: Хранит данные задачи, предоставляет их по запросу и обновляет статус задачи.  
- **NotificationService (NS)**: Уведомляет исполнителя о результате проверки.  
- **Worker**: Получает уведомление о принятии или отклонении задачи.  

**Поток выполнения**:  
1. Менеджер запрашивает детали завершенной задачи.  
2. Система управления задачами извлекает данные задачи из базы данных.  
3. Менеджер проверяет данные задачи.  
4. В зависимости от решения менеджера:  
   - **Если задача принята**:  
     1. Система обновляет статус задачи на «принята».  
     2. Система уведомлений отправляет исполнителю уведомление о принятии задачи.  
   - **Если задача отклонена**:  
     1. Менеджер указывает причину отклонения.  
     2. Система обновляет статус задачи на «отклонена».  
     3. Система уведомлений отправляет исполнителю уведомление об отклонении задачи.  

---

### 3. Операция: Уведомление о статусе задачи
**Описание**: Система уведомлений информирует пользователей об изменении статуса задачи.  
**Участники**:  
- **NotificationService (NS)**: Генерирует и отправляет уведомления.  
- **Manager/Worker**: Получают уведомления о статусе задачи.  

**Поток выполнения**:  
1. Система управления задачами инициирует процесс уведомления при любом изменении статуса задачи.  
2. Система уведомлений формирует сообщение для соответствующего пользователя (менеджера или исполнителя).  
3. Уведомление отправляется в реальном времени.  

---

### 4. Операция: Сохранение изменений задачи
**Описание**: Обеспечение надежного сохранения обновленных данных задачи в базе данных.  
**Участники**:  
- **TaskManagementSystem (TMS)**: Обрабатывает данные для сохранения.  
- **Database (DB)**: Сохраняет данные задачи, включая обновления статуса и другие изменения.  

**Поток выполнения**:  
1. Система управления задачами получает запрос на обновление данных задачи.  
2. Данные отправляются в базу данных.  
3. База данных подтверждает успешное сохранение изменений.  
4. Система возвращает подтверждение инициатору операции.
