## Определения

| Термин                  | Определение                                                                                                        | Формат                        | Правило верификации                                                                              | Синоним                  | Взаимодействие            |
|-------------------------|-------------------------------------------------------------------------------------------------------------------|-------------------------------|---------------------------------------------------------------------------------------------------|--------------------------|-----------------------------|
| **Пользователь**        | Индивид, взаимодействующий с системой учета рабочего времени, включая руководителей, исполнителей и системных администраторов. | Сущность с уникальным ID      | Должен иметь уникальный ID, действительный email и защищённый пароль                                  | Сотрудник, Работник     | -                         |
| **Руководитель**        | Пользователь, который создает и выдает задания, а также отслеживает ход их выполнения.                             | Подкласс Пользователя         | Должен иметь права на создание и выдачу заданий, а также доступ к отчетам о выполнении            | Менеджер,  Тимлид       | -                         |
| **Исполнитель**          | Пользователь, который принимает и выполняет задания, ведет учет рабочего времени.                                  | Подкласс Пользователя         | Должен иметь возможность принимать задания и вести учет времени                                   | Сотрудник                | -                         |
| **Системный администратор**| Пользователь, ответственный за поддержку работоспособности системы, управление настройками и доступом.           | Подкласс Пользователя         | Должен иметь административные права доступа к системе                                             | Администратор,  Сисадмин       | -                         |
| **Задание**             | Задача, поставленная руководителем перед исполнителем, с указанием требований, сроков и ожидаемого результата.     | Сущность с уникальным ID      | Должно иметь краткое и полное описание, срок выполнения, статус и назначенного исполнителя         | Задача                   | -                         |
| **Рабочее время**        | Время, затраченное исполнителем на выполнение задания, учитываемое в часах и минутах.                               | Числовое значение             | Должно быть неотрицательным и не превышать разумные пределы для данного типа заданий                 | Время выполнения         | -                         |
| **Учет рабочего времени** | Процесс регистрации и отслеживания времени, затраченного на выполнение заданий.                                    | Процесс                      | Должно быть обеспечено корректное и точное внесение данных о затраченном времени всеми исполнителями | -                        | -                         |
| **Статус задания**      | Состояние выполнения задания, например: "Новое", "В работе", "Выполнено", "На проверке", "Отклонено".             | Перечисление                 | Должен соответствовать одному из предопределенных статусов                                         | -                        | -                         |
| **Комментарий**          | Дополнительная информация к заданию или учету рабочего времени, например, пояснения, уточнения, проблемы.          | Текстовое поле               | Должен быть информативным и относиться к контексту задания или учету времени                       | Примечание               | -                         |
| **Уведомление**         | Системно-сгенерированное сообщение, информирующее пользователей о важных событиях, таких как новое задание, изменение статуса, приближение срока. | Сущность с уникальным ID      | Должно иметь действительный тип сообщения и получателя                                           | Оповещение, Сообщение     | -                         |
| **Настройки**            | Параметры системы, определяющие ее поведение и доступные функции, настраиваемые администратором.                    | Сущность                     | Должны быть корректно заданы и соответствовать требованиям безопасности и функциональности            | Конфигурация            | -                         |
| **HR-система**          | Система управления персоналом, используемая для учета данных о сотрудниках, отпусках, занятости и т.д.              | Внешняя система              | Должна быть доступна и обеспечивать интеграцию для получения данных о сотрудниках                   | Система управления персоналом | Получение данных о сотрудниках, отпусках |
| **Бухгалтерская система** | Система, используемая для расчета заработной платы, налогов и других финансовых операций.                          | Внешняя система              | Должна быть доступна и обеспечивать интеграцию для передачи данных о рабочем времени для расчета ЗП | Финансовая система        | Передача данных о рабочем времени для расчета ЗП |
